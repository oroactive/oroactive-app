# oroactive-app

## Nomi delle nuove build

Dal prossimo aggiornamento il nome della build segue il formato:

`oroactive_gestionale_<numero>_<YYYYMMDD>`

Il numero incrementa di uno rispetto all'ultima build applicativa pubblicata.
La convenzione è stata introdotta dopo la build 65.
La data è quella dell'aggiornamento nel fuso `Europe/Rome`.
Per esempio, la build 66 aggiornata il 23 ottobre 2026 si chiamerà
`oroactive_gestionale_66_20261023`.

La convenzione completa per preparare le prossime release è in [AGENTS.md](AGENTS.md).
