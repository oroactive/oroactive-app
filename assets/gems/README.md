# Media dell'Enciclopedia Gemmologica

Le fotografie e i video approvati vanno organizzati in:

`assets/gems/<slug-materiale>/`

Per ogni fotografia sono previste, quando disponibili:

- originale HD con lato maggiore di almeno 1600 px;
- versione 1600 px;
- versione 960 px;
- miniatura 480 px;
- varianti WebP compatibili.

Ogni media deve avere fonte, autore, licenza, stato dei diritti, dimensioni originali,
testo alternativo, didascalia e indicazione didattica su cosa osservare. In assenza
di diritti documentati la scheda resta in `needs_media` e mostra il segnaposto
OroActive. Non inserire fotografie casuali recuperate dal web.
